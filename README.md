# CoworkingView for WordPress

Source of the [CoworkingView](https://coworkingview.com) WordPress plugin: shortcodes that show coworking spaces, private offices and market rates for a city, with the prices operators publish. No API key.

- `coworkingview/`: the plugin, as published on wordpress.org.
- `wporg-assets/`: icon and banner for the wordpress.org listing (SVN `assets/`).

```
[coworkingview_spaces city="berlin" type="private_office" limit="5"]
[coworkingview_rates city="madrid"]
```

See [`coworkingview/readme.txt`](coworkingview/readme.txt) for every attribute. License: GPL-2.0-or-later.
